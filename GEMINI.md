# GEMINI.md - Internal Project Information for QuizIQ

This document serves as an internal knowledge base for the Gemini agent, tracking essential project details, configurations, and changes to facilitate efficient and accurate work on the QuizIQ project.

## 1. Project Context

QuizIQ is a web-based adaptive testing system utilizing a 3-Parameter Logistic (3PL) Item Response Theory (IRT) model for personalized assessments. The backend is built with FastAPI and SQLAlchemy, handling IRT logic and database interactions. The frontend is a clean, responsive UI built with HTMX.

## 3. Key Files and Their Roles

*   `app/main.py`: The main FastAPI application entry point, handling routing, dependencies, and HTML responses.
*   `app/models/base.py`: Defines the SQLAlchemy ORM models for the database schema (User, Item, TestSession, etc.). Also contains the database engine setup and `create_db_and_tables` function.
*   `app/core/irt.py`: Contains the core Item Response Theory (IRT) logic, including functions for probability of correct response, theta estimation, and standard error calculation.
*   `seed_db.py`: A script used to populate the database with initial sample data.
*   `tests/unit/test_irt_engine.py`: Pytest unit tests specifically for the IRT engine logic.
*   `pyproject.toml`: Configuration file for project tools, specifically Ruff for static analysis and linting.
*   `requirements.txt`: Lists all Python dependencies required by the project.
*   `setup_env.sh`: A shell script to automate the setup of the Python virtual environment and install dependencies.

## 5. Running Commands

### Running the Application

1.  **Activate virtual environment**: `source .venv_quiz_iq/bin/activate`
2.  **Seed the database**: `python3 seed_db.py`
3.  **Start the server**: `uvicorn app.main:app --reload`
4.  **Access**: `http://127.0.0.1:8000`

### Running Tests

1.  **Activate virtual environment**: `source .venv_quiz_iq/bin/activate`
2.  **Run Pytest**: `pytest tests/ -v`

### Linting

1.  **Activate virtual environment**: `source .venv_quiz_iq/bin/activate`
2.  **Run Ruff check**: `ruff check .`
3.  **Run Ruff fix**: `ruff check . --fix`
